## Sicher Web Interface
An optional add-on that hooks onto the Sicher modularity and provides a web interface for compiling c source programs using sicher and logging various historical data on the left history view.

### Requirements
Place this repo in the same parent directory as the actual Sicher compiler.

### How to Use
python3 web_interface.py
Navigate to the localhost:5000 or run ./run.sh

### Shows
* Tokeniser Logs
* Parser Logs
* Analyser Logs
* Code Generator Logs
* Performance Plots
* Sicher Diagnostics
* History of compilations
